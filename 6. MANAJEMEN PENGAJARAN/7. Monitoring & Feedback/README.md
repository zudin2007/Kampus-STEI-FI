# 7. MONITORING & FEEDBACK

## Deskripsi

Folder ini mengelola sistem monitoring pembelajaran berkelanjutan & pengumpulan feedback, meliputi:
- Monitoring mingguan/bulanan pembelajaran
- Feedback dari mahasiswa tentang pembelajaran
- Early warning system untuk mahasiswa berisiko
- Feedback untuk dosen tentang performa mengajar
- Action planning untuk perbaikan berkelanjutan

## File-File Utama

- `TEMPLATE_MONITORING_MINGGUAN.md` - Template monitoring mingguan
- `TEMPLATE_SURVEI_PEMBELAJARAN.md` - Template survei kepuasan pembelajaran
- `TEMPLATE_EVALUASI_DOSEN.md` - Template evaluasi dosen oleh mahasiswa
- `TEMPLATE_EARLY_WARNING_SYSTEM.md` - Template identification mahasiswa berisiko
- `TEMPLATE_ACTION_PLAN_IMPROVEMENT.md` - Template action plan perbaikan

## Komponen-Komponen Monitoring

### A. Monitoring Pembelajaran

**Apa yang Dimonitor:**
- [ ] Kehadiran dosen & mahasiswa
- [ ] Progress materi perkuliahan
- [ ] Kualitas pembelajaran (metode, engagement)
- [ ] Pencapaian learning outcomes sementara
- [ ] Kendala/masalah pembelajaran

**Frekuensi & PIC:**
- **Mingguan:** Dosen self-monitoring + spot check dari Kaprodi
- **Bi-weekly:** Review progress dari Kaprodi
- **Mid-semester (Minggu 8):** Comprehensive assessment
- **End-semester:** Final evaluation & learning outcomes analysis

**Tools:**
- Checklist monitoring mingguan
- Progress tracking spreadsheet
- Classroom observation form
- Data nilai sementara

### B. Feedback Mahasiswa

**Apa yang Ditanyakan:**
- Learning outcomes clarity
- Materi relevance & kualitas
- Metode pembelajaran effectiveness
- Communication & feedback dari dosen
- Penilaian fairness & transparency
- Sarana prasarana quality
- Overall satisfaction

**Frekuensi:**
- **Mid-semester:** Quick pulse survey (5-10 menit)
- **End-semester:** Comprehensive survey (10-15 menit)

**Format:**
- Online survey (Google Form, Qualtrics)
- Paper-based (jika online tidak feasible)
- Focus group discussion (optional, untuk deeper insights)

**Response Rate Target:** ≥70%

### C. Evaluasi Dosen oleh Mahasiswa

**Dimensi yang Dievaluasi:**
- Content mastery
- Teaching effectiveness
- Communication & clarity
- Student engagement & interaction
- Fairness dalam penilaian
- Accessibility & support to students
- Professionalism & punctuality

**Skala:** 1-5 (Poor to Excellent)

**Target Score:** ≥3.5 dari 5

**Frekuensi:** 1x per semester (end-of-semester)

### D. Early Warning System (Mahasiswa Berisiko)

**Indikator Mahasiswa Berisiko:**

| Indikator | Threshold |
|-----------|-----------|
| Kehadiran | <80% |
| Nilai UTS | <60 |
| Partisipasi | Rendah/tidak ada |
| Tugas | Sering terlambat/tidak submit |
| Performa mid-term | <60% dari expected |

**Prosedur:**
1. **Identification:** Identify mahasiswa berisiko setiap minggu
2. **Communication:** Hubungi mahasiswa, cari tahu masalahnya
3. **Support:** Tawarkan bantuan (tutorial, mentoring, flexible deadline)
4. **Monitoring:** Follow-up progress setiap 2 minggu
5. **Escalation:** Jika tidak improve, escalate ke Kaprodi

**Output:** Early warning list & action plans

### E. Feedback untuk Dosen

**Sumber Feedback:**
- Student evaluations
- Peer observation
- Self-reflection
- Monitoring data
- Learning outcomes achievement

**Timing Feedback:**
- Mid-semester: Quick feedback untuk real-time adjustment
- End-semester: Comprehensive feedback untuk improvement planning

**Format Feedback:**
- Written report
- One-on-one meeting
- Coaching session
- Group discussion (jika relevant)

**Prinsip Feedback:**
- Constructive, bukan critical
- Specific dengan contoh
- Actionable dengan suggestions
- Balance: strength + area for improvement

## Sistem Monitoring: Detail Prosedur

### Prosedur A: Monitoring Mingguan

**Timeline:**
- Setiap akhir minggu (Jumat)
- Kaprodi review laporan dosen
- Monday pagi: Follow-up jika ada isu urgent

**Checklist Mingguan:**
- Dosen attendance
- Mahasiswa attendance (average)
- Materi sesuai RPS?
- Ada kendala/masalah?
- Nilai dicatat?
- Feedback diberikan?

**Action:**
- Tandai isu yang perlu follow-up
- Brief chat dengan dosen jika urgent
- Compile summary untuk bulan

### Prosedur B: Mid-Semester Assessment (Minggu 8)

**Aktivitas:**
1. Collect nilai UTS dari dosen
2. Administrasikan survei pembelajaran
3. Collect data kehadiran & performance
4. Analisis data: identifikasi pattern
5. Rapat koordinasi: diskusi hasil, action plan

**Analisis:**
- Distribusi nilai UTS: normal?
- % mahasiswa <60: ada yang berisiko?
- Kepuasan pembelajaran: ada issue?
- Learning outcomes: track towards 80%?

**Output:**
- Data summary
- List mahasiswa berisiko
- Action plan (intervensi, metode adjustment, etc)
- Communication ke mahasiswa

### Prosedur C: End-of-Semester Evaluation (Post-UAS)

**Aktivitas:**
1. Collect nilai final dari dosen
2. Administrasikan survei kepuasan pembelajaran
3. Administrasikan evaluasi dosen oleh mahasiswa
4. Analisis pembelajaran outcomes
5. Meeting refleksi dengan dosen

**Analisis:**
- Distribusi nilai final
- % kelulusan per mata kuliah
- Learning outcomes achievement rate
- Kepuasan pembelajaran score
- Evaluasi dosen score

**Output:**
- Laporan pembelajaran semester
- Evaluasi dosen
- List dosen dengan isu (untuk follow-up)
- Best practices yang berhasil
- Recommendation untuk semester depan

## Handling Feedback & Action Planning

### Mahasiswa Feedback
**If score <3.5 untuk item tertentu:**
1. Analyze: Apa yang menjadi issue?
2. Discuss dengan dosen: apa insight dosen?
3. Identify: Apa yang bisa diperbaiki?
4. Plan: Action konkrit untuk perbaikan
5. Follow-up: Monitor improvement semester depan

### Evaluasi Dosen <3.5
**Protocol:**
1. Private meeting: Kaprodi + dosen
2. Discuss: Feedback dari mahasiswa
3. Explore: Root causes
4. Plan: Development plan untuk improvement
5. Support: Provide training, mentoring, resources
6. Monitor: Follow-up next semester

## Best Practices

1. **Data-Driven:** Base decisions on data, bukan feeling
2. **Timely:** Monitor real-time, bukan post-facto
3. **Actionable:** Feedback harus actionable dengan clear action
4. **Constructive:** Frame sebagai improvement opportunity, bukan criticism
5. **Transparent:** Share hasil dengan stakeholders relevant
6. **Continuous:** Ongoing, bukan one-time
7. **Supportive:** Support dosen & mahasiswa untuk improve

## Tantangan & Solusi

| Tantangan | Solusi |
|-----------|--------|
| Low survey response | Incentive, make easier, in-class completion |
| Dosen defensive terhadap feedback | Frame positif, private discussion, coaching approach |
| Slow action implementation | Clear deadline, accountability, incentive |
| Data incomplete/inaccurate | Validation process, reminders, training |
