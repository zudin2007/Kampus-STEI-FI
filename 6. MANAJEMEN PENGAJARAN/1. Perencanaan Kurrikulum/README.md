# 1. PERENCANAAN KURIKULUM

## Deskripsi

Folder ini mengelola perencanaan dan pengembangan kurikulum program studi, termasuk:
- Analisis kebutuhan kompetensi lulusan
- Pengembangan struktur kurikulum
- Pemetaan learning outcomes
- Keselarasan dengan standar akreditasi

## File-File Utama

- `TEMPLATE_STRUKTUR_KURIKULUM.md` - Template struktur kurikulum
- `TEMPLATE_LEARNING_OUTCOMES.md` - Template learning outcomes mapping
- `CHECKLIST_KUALITAS_KURIKULUM.md` - Checklist verifikasi kurikulum

## Proses Pengembangan Kurikulum

1. **Analisis Kebutuhan** (6-12 bulan sebelum implementasi)
2. **Design Kurikulum** (4-6 bulan sebelum)
3. **Verifikasi & Approval** (2-3 bulan sebelum)
4. **Disseminasi & Training** (1-2 bulan sebelum)
5. **Implementasi & Monitoring** (Ongoing)

## Stakeholder Utama

- Kaprodi
- Dosen Senior
- Tim Kurikulum
- Industri/Profesional
- Alumni

## Catatan

Folder ini akan dikembangkan lebih lanjut dengan template-template kurikulum yang komprehensif.
