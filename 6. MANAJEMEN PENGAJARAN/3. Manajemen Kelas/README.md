# 3. MANAJEMEN KELAS

## Deskripsi

Folder ini mengelola aspek operasional pembelajaran di kelas, meliputi:
- Jadwal perkuliahan & ruang kuliah
- Pencatatan kehadiran dosen & mahasiswa
- Manajemen sarana prasarana (laboratorium, peralatan)
- Kontrak pembelajaran & disiplin kelas
- Komunikasi dengan mahasiswa

## File-File Utama

- `TEMPLATE_JADWAL_PERKULIAHAN.md` - Template jadwal semester
- `TEMPLATE_DAFTAR_HADIR.md` - Template pencatatan kehadiran
- `TEMPLATE_KONTRAK_PEMBELAJARAN.md` - Template kontrak pembelajaran
- `CHECKLIST_MANAJEMEN_RUANG.md` - Checklist manajemen ruang/lab
- `TEMPLATE_KOMUNIKASI_MAHASISWA.md` - Template komunikasi class

## Komponen-Komponen Utama

### A. Jadwal Perkuliahan
- Koordinasi jadwal dengan registrar/admin
- Avoid double-booking ruang & dosen
- Optimasi ruang (efisiensi, proximity)
- Publish jadwal early (minimal 2 minggu sebelum semester)
- Monitor perubahan & inform mahasiswa

### B. Kehadiran Dosen
- Dosen hadir tepat waktu (5 menit sebelum kuliah dimulai)
- Jika berhalangan, inform mahasiswa advance
- Maksimal 1 absence per semester (kecuali situasi luar biasa)
- Tanggungjawab: Kaprodi monitoring, Dosen melapor

### C. Kehadiran Mahasiswa
- Target kehadiran minimum: 80%
- Dokumentasi: nama, tanggal, jam (jika ada)
- Sistem: manual checklist atau teknologi (QR code, fingerprint)
- Feedback: jika kehadiran <80%, follow-up dengan mahasiswa
- Escalation: jika kehadiran <60%, koordinasi dengan Kaprodi

### D. Kontrak Pembelajaran
- Disusun minggu pertama perkuliahan
- Konten: Learning outcomes, metode, penilaian, aturan kelas
- Ditandatangani dosen & mahasiswa
- Enforcement: kedua pihak berkomitmen mengikuti

### E. Manajemen Ruang & Lab
- Booking ruang sebelum perkuliahan
- Kondisi ruang acceptable (kebersihan, AC, equipments)
- Lab: keamanan equipment, log book penggunaan
- Maintenance: report kerusakan immediately
- Cleaning schedule: responsibility sharing

### F. Komunikasi Kelas
- Channel: Email, WhatsApp, Learning Management System
- Frekuensi: Sesuai kebutuhan (announcement, urgent info, etc)
- Content: Materi perkuliahan, deadline tugas, pengumuman penting
- Responsiveness: Dosen respond dalam 24 jam

## Standard Operating Procedures

### Prosedur A: Setup Kelas di Awal Semester

1. Finalisasi jadwal (2 minggu sebelum)
2. Pastikan ruang & equipment ready (1 minggu sebelum)
3. Susun kontrak pembelajaran
4. Pertemuan pertama: introduce self, explain LO, sign kontrak
5. Setup communication channel
6. Mulai dokumentasi kehadiran

### Prosedur B: Monitoring Kehadiran Mingguan

1. Dosen catat kehadiran setiap perkuliahan
2. Update data kehadiran (harian atau minggu)
3. Kaprodi review data (bi-weekly)
4. Jika ada masalah (dosen/mahasiswa), follow-up
5. Report progress (monthly)

### Prosedur C: Handling Kehadiran <80%

**Jika Mahasiswa:**
1. Send warning message (email/whatsapp)
2. Invite discussion: apa masalahnya?
3. Offer support: tutorial, flexible schedule, etc
4. Follow-up 2 minggu: ada improvement?
5. Jika masih <60%: escalate ke Kaprodi

**Jika Dosen:**
1. Kaprodi discuss dengan dosen (private conversation)
2. Cari tahu penyebab absence
3. Arrange coverage jika perlu
4. Monitor improvement
5. Document untuk evaluation

## Best Practices

1. **Consistency:** Setup yang sama untuk semua kelas
2. **Transparency:** Mahasiswa tahu ekspektasi sejak hari pertama
3. **Fairness:** Aturan diterapkan konsisten untuk semua
4. **Proactive:** Follow-up masalah kehadiran before terlambat
5. **Data-Driven:** Gunakan data untuk decision making
