# 6. MANAJEMEN PENGAJARAN

## Deskripsi

Folder **Manajemen Pengajaran** menyediakan sistem terintegrasi untuk pengelolaan aktivitas pembelajaran di tingkat program studi/prodi. Folder ini mencakup seluruh siklus pengajaran dari perencanaan hingga evaluasi dan pengembangan berkelanjutan.

## Struktur Folder

### 1. Perencanaan Kurikulum
- Pengembangan struktur kurikulum
- Keselarasan dengan learning outcomes
- Pemetaan kompetensi lulusan
- Template perencanaan pembelajaran tahunan

### 2. Pengembangan RPS (Rencana Pembelajaran Semester)
- Template RPS standar
- Panduan penulisan RPS
- Checklist kualitas RPS
- Sinkronisasi RPS dengan kurikulum

### 3. Manajemen Kelas
- Jadwal perkuliahan
- Manajemen kehadiran
- Manajemen ruang/laboratorium
- Kontrak pembelajaran dengan mahasiswa

### 4. Penilaian & Evaluasi
- Rubrik penilaian
- Rancangan sistem penilaian semester
- Analisis hasil pembelajaran
- Validasi dan standar nilai

### 5. Inovasi Pembelajaran
- Metode pembelajaran alternatif
- Integrasi teknologi pembelajaran
- Case study pembelajaran efektif
- Panduan flipped classroom dan blended learning

### 6. Pengembangan Dosen
- Program pengembangan kompetensi dosen
- Workshop dan pelatihan
- Refleksi pembelajaran dosen
- Sertifikasi dan akreditasi dosen

### 7. Monitoring & Feedback
- Template monitoring pembelajaran mingguan/bulanan
- Sistem feedback mahasiswa
- Identifikasi kesulitan pembelajaran
- Action plan perbaikan pembelajaran

## Panduan Penggunaan

1. **Untuk Kepala Program Studi (Kaprodi):**
   - Gunakan folder ini untuk memastikan semua dosen mengikuti standar pembelajaran
   - Lakukan monitoring mingguan/bulanan
   - Fasilitasi pengembangan dosen berkelanjutan

2. **Untuk Dosen Pengampu:**
   - Ikuti template RPS dan manajemen kelas
   - Terapkan sistem penilaian yang transparan
   - Berpartisipasi dalam program pengembangan dosen
   - Berikan feedback kepada program studi

3. **Untuk Tim Manajemen Pembelajaran:**
   - Koordinasikan dengan semua folder yang ada
   - Pastikan sinkronisasi dengan folder "4. AKADEMIK & PEMBELAJARAN"
   - Monitor trende dan isu pembelajaran
   - Fasilitasi inovasi pembelajaran

## File-File Utama

- `MANAJEMEN_PENGAJARAN_OVERVIEW.md` - Ringkasan eksekutif
- `MANAJEMEN_PENGAJARAN_CHECKLIST.md` - Checklist bulanan
- `SOP_MONITORING_PEMBELAJARAN.md` - Standar operasional
- Template untuk setiap subfolder dalam format Markdown dan Excel

## Integrasi dengan Folder Lain

- **1. AKREDITASI & REGULASI** - Pemenuhan standar akreditasi pembelajaran
- **2. KEPEMIMPINAN & MANAJEMEN** - Koordinasi strategis pengajaran
- **4. AKADEMIK & PEMBELAJARAN** - Implementasi teknis pembelajaran
- **Template Root Level** - Penggunaan template email, checklist, dan notifikasi

## Catatan Penting

- Semua dokumen dalam folder ini mengikuti standar PUEBI
- Template dapat dikustomisasi sesuai kebutuhan program studi
- Update berkala diperlukan untuk memastikan relevansi dengan perkembangan terbaru
- Feedback dari dosen dan mahasiswa harus dikumpulkan secara berkala
