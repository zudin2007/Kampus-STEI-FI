#### **SEGMENT 3: Data Quality Standards & Validation (10:30-10:50)**
**Speaker:** LPM Director

**Script:**
```
Sekarang mari kita discuss quality standards. Ini adalah yang akan membedakan 
good data dari bad data.

Ketika kami bilang "data accuracy ≥95%", apa artinya?

Itu berarti: dari 100 data points yang Anda submit, maksimal 5 yang bisa 
punya error atau inconsistency. Lebih dari itu, kami akan ask untuk revision.

Gimana cara ensure accuracy ≥95%?

STEP 1: Data Validation Checklist
Sebelum submit data, Anda HARUS cross-check dengan checklist ini:
□ Apakah data source saya credible? (official dokumen, bukan estimasi)
□ Apakah data ini terbaru? (tidak pakai data lama)
□ Apakah numbers saya consistent? (cek di multiple sources)
□ Apakah saya punya evidence untuk setiap claims? (dokumen, bukti foto)
□ Apakah format saya standard? (following template yang provided)

STEP 2: Common Errors to Avoid
- Typo di numbers (5000 menjadi 50000)
- Missing data points (submit incomplete data)
- Inconsistent formatting (tabel format tidak sama)
- No source documentation (tidak tahu dari mana datanya)
- Outdated information (pakai 2024 untuk tahun 2025)
- Approximate numbers (bilang "sekitar 150 mahasiswa" instead of exact 147)

STEP 3: Evidence Documentation
Untuk setiap data point, especially quantitative, Anda perlu:
1. Source dokumen (laporan, database, etc)
2. Date of data (kapan ini collected)
3. Prepared by (siapa yang compile)
4. Notes/context (penjelasan jika diperlukan)

Contoh BAIK:
| Data | Value | Source | Date | Notes |
|------|-------|--------|------|-------|
| Mahasiswa aktif | 547 | Database registration | Aug 31, 2026 | End of sem data |

Contoh BURUK:
| Data | Value |
|------|-------|
| Students | ~550 |

STEP 4: Template Usage
Semua template yang sudah kami provide harus DIGUNAKAN. 
Jangan create template sendiri. Mengapa? Karena nanti saat compile, 
format tidak sama dan kami akan spend banyak waktu rework.

Template sudah dengan formula, dengan validation rules. 
Please gunakan template "AS IS" tanpa modification.

Sekarang mari kita lihat timeline submission dan process revisions.
```

**Key Materials to Show:**
- Sample data validation checklist
- Common errors examples (good vs bad data)
- Template screenshot showing format
- Evidence documentation requirements
