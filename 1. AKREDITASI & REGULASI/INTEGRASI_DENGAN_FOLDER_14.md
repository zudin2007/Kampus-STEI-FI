## 🔗 CROSS-REFERENCING

### **Ketika Menggunakan Folder 1 Materials:**
1. **Ambil dari Folder 1:**
   - SOP procedures → Reference existing documents
   - Form templates → F-PRODI-01 through F-PRODI-11
   - Faculty data → BKD Dosen, NIDN/NUPTK data
   - Academic calendar → KALENDER AKADEMIK

2. **Gunakan dalam Folder 14 Context:**
   - Map ke standar yang sesuai (BAN_PT_7_STANDAR.md)
   - Validate terhadap KPI targets (KPI_INDIKATOR_AKREDITASI.md)
   - Include dalam evidence compilation (Dokumen_Pendukung/)
   - Track dalam monitoring (AKREDITASI_MONITORING_CHECKLIST.md)

### **Ketika Menggunakan Folder 14 Framework:**
1. **Ambil guidance dari Folder 14:**
   - Strategic direction → AKREDITASI_OVERVIEW.md
   - Standar requirements → BAN_PT_7_STANDAR.md
   - Timeline deadlines → TIMELINE_AKREDITASI.md
   - KPI targets → KPI_INDIKATOR_AKREDITASI.md

2. **Implement menggunakan Folder 1 Materials:**
   - Execute menggunakan existing SOP (Folder 1)
   - Complete forms per procedure (Folder 1)
   - Document hasil per KPI framework (Folder 14)
   - Quality check per LPM standards (Folder 14)

## 🚀 IMPLEMENTASI TAHAP DEMI TAHAP

### **Fase 1-2 (W1-4): Setup & Data Collection**
1. Review Folder 14 strategic docs (OVERVIEW, STANDARDS, CHECKLIST)
2. Reference Folder 1 SOP untuk execution
3. Collect data using Folder 1 forms & procedures
4. Validate per Folder 14 KPI targets

### **Fase 3 (W5-10): SER Drafting & Review**
1. Use Folder 14 BAN-PT standards sebagai framework
2. Reference Folder 1 evidence documents
3. Draft SER di Folder 14 / Self_Evaluation_Report/
4. Quality review per Folder 14 / LPM_AKREDITASI_KOORDINASI.md

### **Fase 4 (W11-14): Finalization & Submission**
1. Finalize evidence collection (Folder 1 → Folder 14/Dokumen_Pendukung/)
2. Complete SER per Folder 14 standards
3. Submit per Folder 14 TIMELINE
4. Monitor per Folder 14 AKREDITASI_MONITORING_CHECKLIST.md

### **Fase 5 (W15+): Visitasi & Follow-up**
1. Prepare presentasi dengan Folder 14 data
2. Organize evidence per Folder 1 SOP & procedures
3. Document feedback dalam Folder 14 / Laporan_Komunikasi/
4. Track action plan dalam Folder 14 monitoring
