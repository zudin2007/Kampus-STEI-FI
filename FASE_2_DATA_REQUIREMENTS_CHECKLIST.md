## 🎯 OVERVIEW

This document provides **exact data requirements** for each of the 7 BAN-PT Standards. Use this as your master checklist for data collection across all 3 weeks of Phase 2.

Each data point has:
- **Data Type:** What kind of information (quantitative, qualitative, document)
- **Source:** Where to get it
- **Owner:** Which unit is responsible
- **Format:** How to submit it
- **Evidence:** What documentation required
- **Accuracy Target:** Acceptable error margin
- **Priority:** W2 (50%), W3 (85%), or W4 (100%) submission

## 📊 DATA SUBMISSION FORMAT STANDARDS

### **Format Excel (untuk data kuantitatif):**
```
Column 1: Item/Category
Column 2: 2024
Column 3: 2025
Column 4: 2026
Column 5: Comments/Notes

Rows: Data points

Include:
- Sheet name: Standar [number]
- Header with unit name, date prepared, prepared by
- Data source citation
- Any assumptions or notes
- Total row if applicable
```

### **Format Document (untuk data kualitatif/policy):**
```
- Document title: Clear and specific
- Date of approval/publication
- Version number
- Source/owner
- 1-2 page summary if document is long
- Highlight relevant sections for accreditation
```

### **Format Photos:**
```
Filename: [STANDAR_FACILITY_DATE.jpg]
Examples: [01_GOVERNANCE_MEETING_20260907.jpg]

Requirements:
- Clear, well-lit photos
- Label visible (if possible)
- Include people for scale if appropriate
- Timestamp metadata preserved
- Minimum resolution: 1024x768
```

## 🔍 VALIDATION CHECKLIST (LPM Review)

For each data point, LPM will verify:
- [ ] **Source credibility** - Data comes from official record
- [ ] **Timeliness** - Data is current (not outdated)
- [ ] **Accuracy** - Numbers are correct, consistent with other sources
- [ ] **Completeness** - All required evidence provided
- [ ] **Format** - Follows template and standards
- [ ] **Documentation** - Source cited, prepared by named
- [ ] **Consistency** - Data aligns with other Standar data
