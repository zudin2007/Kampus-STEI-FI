## 📋 DOCUMENTATION CHECKLIST

### **STANDAR 4: MAHASISWA & LULUSAN**

**Dokumen yang Diperlukan:**

- [ ] **Data Mahasiswa 3-Tahun**
  - [ ] Enrollment data (intake, retention)
  - [ ] Student profile (age, background)
  - [ ] Academic progress (GPA, completion rate)
  - [ ] Retention rate per cohort
  - [ ] Graduation rate (on-time vs delayed)

- [ ] **Student Satisfaction Survey**
  - [ ] Survey instrument & methodology
  - [ ] Results (score ≥4.0/5.0 on key dimensions)
  - [ ] Trend analysis (improving?)
  - [ ] Action plan for improvements

- [ ] **Alumni Tracer Study**
  - [ ] Employment rate (target: ≥90%)
  - [ ] Time to employment
  - [ ] Job relevance to degree
  - [ ] Employer satisfaction
  - [ ] Alumni engagement

- [ ] **Student Services Documentation**
  - [ ] Academic counseling records
  - [ ] Financial aid distribution
  - [ ] Career services activities
  - [ ] Student health services
  - [ ] Student grievance resolution

- [ ] **Student Organizations & Activities**
  - [ ] List of active organizations
  - [ ] Participation rate (≥80%)
  - [ ] Event attendance records
  - [ ] Leadership development programs
  - [ ] Community engagement

---

### **STANDAR 6: SARANA & PRASARANA - FACILITIES**

**Dokumen yang Diperlukan:**

- [ ] **Facility Inventory Complete**
  - [ ] Asset register (all items)
  - [ ] Real property: Offices, classrooms, labs
  - [ ] Furniture & equipment
  - [ ] Technology infrastructure
  - [ ] Learning spaces photos

- [ ] **Learning Facilities**
  - [ ] Lecture halls: Quantity, capacity, equipment
  - [ ] Laboratories: Equipment list, condition
  - [ ] Library: Collections, e-resources
  - [ ] Computer lab: Specs, maintenance
  - [ ] Study spaces: Adequacy assessment

- [ ] **Support Facilities**
  - [ ] Student center: Services, accessibility
  - [ ] Cafeteria: Quality, hygiene
  - [ ] Parking: Capacity, utilization
  - [ ] Restrooms: Quantity, condition
  - [ ] Prayer facility: Availability

- [ ] **Maintenance & Safety**
  - [ ] Maintenance schedule: Preventive + corrective
  - [ ] Maintenance logs: All items documented
  - [ ] Safety compliance: Fire, electrical, emergency
  - [ ] Insurance coverage: Building + contents
  - [ ] Incident records: None or properly handled

- [ ] **Infrastructure Sustainability**
  - [ ] Maintenance budget: Adequate & allocated
  - [ ] Upgrade plan: 3-year documented
  - [ ] Utilization rate: ≥70% for academic spaces
  - [ ] Condition assessment: Good or better
  - [ ] Sustainability plan: Long-term viability
