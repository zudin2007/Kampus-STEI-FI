## 📅 NOTIFIKASI HARIAN (Daily Reminders)

### ⏰ Pagi (08:00)

- [ ] Check if any dosen/mahasiswa perlu urgent follow-up

### 🕐 Siang (12:00)
- [ ] Monitor RPS/SK Mengajar submission progress (jika fase persiapan)
- [ ] Check monitoring reports dari dosen (jika fase operasional/monitoring)
- [ ] Review any urgent issues/blockers

### 🌙 Sore (16:00)
- [ ] Siapkan komunikasi/email untuk deadline besok
- [ ] Finalize any documents yang perlu di-send hari ini
- [ ] Update TASKS.md dengan progress

## 📊 NOTIFIKASI BULANAN (Monthly Checklist)

### AKHIR BULAN (Last Friday, 10:00 AM)
**Meeting:** Monthly Assessment  
**Peserta:** WK1, Kaprodi, Dekan  
**Durasi:** 2 hours

#### SEBELUM MEETING - Persiapan (Hari Rabu)
- [ ] Compile bulanan summary report
- [ ] Analyze KPI data (attendance, satisfaction, LO achievement, etc)
- [ ] Identify trends & issues
- [ ] Prepare recommendations & action items

**KPI Review (dari WK1_DASHBOARD_MONITORING.md):**
- [ ] RPS Approved (target: 100%)
- [ ] Dosen Attendance (target: ≥95%)
- [ ] Mahasiswa Attendance (target: ≥80%)
- [ ] Mahasiswa Satisfaction (target: ≥3.5/5)
- [ ] LO Achievement (target: ≥80%)
- [ ] Mahasiswa Berisiko (target: <5%)

#### SAAT MEETING - Presentasi
- [ ] Summary bulan ini vs bulan lalu
- [ ] KPI vs target (on track? behind?)
- [ ] Issues & root causes
- [ ] Mitigation & corrective actions
- [ ] Success stories & learnings

#### SETELAH MEETING - Action Items
- [ ] Finalize bulanan summary report
- [ ] Send to Dekan dengan KPI data
- [ ] Update action items tracker
- [ ] Schedule follow-up jika ada issues

**Report Distribution:**
- [ ] Submit ke Dekan (deadline: akhir bulan +3 hari)
- [ ] CC Kaprodi & Admin
- [ ] Include: Summary, KPI data, issues, actions
