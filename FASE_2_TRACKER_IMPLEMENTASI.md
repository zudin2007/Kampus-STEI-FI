## 🚨 ESCALATION PROTOCOL

**If Behind Schedule:**
1. [ ] Notify Koordinator immediately
2. [ ] Assess root cause (resource? complexity? blocker?)
3. [ ] Activate recovery plan (prioritize critical data)
4. [ ] Report to WK/Rektor with timeline adjustment
5. [ ] Monitor daily until back on track

**If Quality Issues Persist:**
1. [ ] Document specific accuracy gaps
2. [ ] Identify source (data owner responsibility? template issue? misunderstanding?)
3. [ ] Provide targeted support (coaching, examples, resources)
4. [ ] Set revision deadline (2-3 days max)
5. [ ] Re-review & approve

**If Data Cannot Be Found:**
1. [ ] Check alternative sources (other departments, prior records)
2. [ ] Document that search was exhaustive
3. [ ] Note "data not available" in SER with action plan
4. [ ] Do NOT delay other Standar for this
5. [ ] Include in post-accreditation improvement plan

**If Critical Blocker:**
1. [ ] Escalate to Rektor immediately
2. [ ] Determine impact on Phase 2 timeline
3. [ ] Authorize resources/support needed
4. [ ] Adjust plan if necessary (but W4 deadline is FIXED)
