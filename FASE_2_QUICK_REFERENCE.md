## 📊 DATA SUBMISSION PROCESS (SIMPLE!)

**For Each Standar, Do This:**

1. **Prepare Data**
   - Use template (provided in email)
   - Gather evidence (documents, photos)
   - Document source (where did it come from?)
   - Verify accuracy (check numbers twice)

2. **Submit Data**
   - Email to: `koordinator@kampussteifi.ac.id`
   - Subject: `DATA SUBMISSION - [STANDAR] - [YOUR UNIT] - W[WEEK]`
   - CC: LPM Director + your WK
   - Attach: Excel file + evidence folder

3. **Follow Quality Standards**
   - Use provided template (no custom formats!)
   - Evidence documented (source + date)
   - Accuracy ≥95% (close enough = problems)
   - Completeness 100% (don't leave blanks)

4. **If Feedback Received**
   - LPM sends feedback within 2 days
   - You revise within 3 days
   - Resubmit and it gets validated again
   - Max 2 revision rounds per Standar

## ✅ QUALITY CHECKLIST (Before You Submit)

**Ask yourself:**

- [ ] Did I use the provided template? (Don't create my own format)
- [ ] Are all numbers accurate? (Verify against source documents)
- [ ] Is everything current? (Not old data from 2024?)
- [ ] Do I have evidence for every claim? (Documents, not guesses)
- [ ] Is the format consistent? (Columns align, dates formatted same way)
- [ ] Did I document the source? (Where did this come from?)
- [ ] Is it complete? (Any blank fields or missing items?)

**If any "NO" answers:** → Don't submit yet, fix first!

## 💡 PRO TIPS FOR SUCCESS

✅ **Start early** - Don't wait until Thursday to collect data  
✅ **Ask questions** - Better to ask now than submit wrong data  
✅ **Document sources** - Every data point needs a "where did this come from" note  
✅ **Verify numbers** - Check against multiple sources if possible  
✅ **Complete = good** - Finish the 50% before Friday, don't rush  
✅ **Attend meetings** - Hearing it twice helps (meeting + follow-up email)  
✅ **Communicate blockers** - Don't hide problems, flag them early
