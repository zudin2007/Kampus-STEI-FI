## 📥 JENIS DOKUMEN YANG DISIMPAN

### 1. **Dokumen Kebijakan/Keputusan**
- SK penetapan visi-misi
- SK struktur organisasi
- Policy statement (mutu, governance)
- Regulasi akademik

### 2. **Data & Laporan**
- Laporan keuangan audited
- Laporan kinerja tahunan
- Data statistik mahasiswa/dosen
- Database publikasi & penelitian

### 3. **Bukti Aktivitas**
- RPS mata kuliah
- Program pengembangan SDM
- Program pengabdian
- Kegiatan penelitian

### 4. **Hasil Evaluasi & Survey**
- Survey kepuasan (dosen, mahasiswa, staf)
- Hasil evaluasi pembelajaran
- Tracer alumni
- Evaluasi diri internal

### 5. **Sertifikat & Penghargaan**
- Sertifikat dosen (S2/S3)
- Sertifikat akreditasi (ISO, program studi)
- Penghargaan & prestasi

## ✅ CHECKLIST KELENGKAPAN

Sebelum submission SER, pastikan:

- [ ] Semua dokumen per standar terkumpul
- [ ] Dokumen dalam format yang baik (PDF/Excel)
- [ ] Dokumen terorganisir per standar
- [ ] Index dokumen lengkap (label & nomor)
- [ ] Backup dokumen tersimpan (hard disk, cloud)
- [ ] Dokumen dapat diakses & dipresentasikan

## 🗂️ CARA PENYIMPANAN

### Naming Convention
```
[Standar]_[Jenis_Dokumen]_[Periode/Tahun].pdf
Contoh: Standar1_RencanaStrategi_2024-2028.pdf
        Standar3_DataDosen_2024.xlsx
```

### Soft Copy
- Simpan di folder digital terstruktur
- Backup di cloud (Google Drive, OneDrive)
- Backup di external hard disk

### Hard Copy
- Print dokumen penting (untuk presentasi)
- Binding per standar untuk kelengkapan
- Label & nomor urut yang jelas
