# 🔗 LPM - AKREDITASI KOORDINASI

**Koordinasi antara LPM (Quality Assurance) dan Koordinator Akreditasi untuk memastikan akurasi data, kelengkapan dokumen, dan kualitas persiapan akreditasi**

---

## 📊 PERAN LPM DALAM AKREDITASI

### LPM Primary Responsibilities

| Tanggung Jawab | Deskripsi | Timeline | Owner |
|---|---|---|---|
| **Data Validation** | Verifikasi akurasi semua data & KPI | Ongoing | LPM |
| **Document Quality** | QC dokumen & evidence sebelum submit | W1-W14 | LPM |
| **Evidence Completeness** | Audit kelengkapan dokumen per standar | W1-W14 | LPM |
| **Compliance Check** | Cek compliance dengan standar BAN-PT | W5-W14 | LPM |
| **SER Review** | Review kualitas SER sebelum approval | W7-W10 | LPM |
| **Monitoring & Feedback** | Monitoring progress & provide feedback | Ongoing | LPM |

## 🔄 KOORDINASI TIMELINE

### **MINGGU 1-2: Persiapan Awal**

#### LPM Tasks:
- [ ] Review panduan BAN-PT (7 standar detail)
- [ ] Develop checklist quality BAN-PT compliance
- [ ] Coordinate dengan Koordinator Akreditasi tentang quality standards
- [ ] Prepare audit protocols untuk data validation
- [ ] Setup quality gate process untuk setiap fase

**Deliverable:** Quality standards & audit protocol siap

**Owner:** LPM Director | **Deadline:** End of Week 2

---

### **MINGGU 2-4: Data Validation**

#### LPM Tasks:
- [ ] Develop validation checklist per standar:
  - [ ] Standar 1: Visi-misi validation
  - [ ] Standar 2: Governance documentation check
  - [ ] Standar 3: Dosen data accuracy audit
  - [ ] Standar 4: Mahasiswa data verification
  - [ ] Standar 5: RPS completeness check
  - [ ] Standar 6: Keuangan & fasilitas audit
  - [ ] Standar 7: Publikasi & research validation

- [ ] Cross-check data:
  - Dosen data (HR system vs actual qualification)
  - Mahasiswa data (enrollment vs Registrar vs actual)
  - Keuangan (audit report vs actual)
  - Publikasi (database vs actual publication)

- [ ] Identify data gaps & inaccuracies
- [ ] Provide feedback ke unit untuk data correction
- [ ] Verify correction & update

**Quality Gate:**
```
LPM VALIDATION CHECKLIST (Per Standar)
├─ Data Accuracy: ☑ Pass / ☐ Needs Review
├─ Completeness: ☑ Pass / ☐ Missing Items
├─ Consistency: ☑ Pass / ☐ Conflict
└─ Evidence Ready: ☑ Pass / ☐ Gap
```

**Owner:** LPM Team + Unit Heads | **Deadline:** End of Week 4

---

### **MINGGU 5-6: SER Draft Review**

#### LPM Tasks:
- [ ] Review SER draft setiap standar untuk:
  - Compliance dengan BAN-PT requirement
  - Data accuracy (fact-checking)
  - Evidence reference completeness
  - Writing quality & clarity
  - Logical structure & flow

- [ ] Provide feedback template per standar:
  ```
  STANDAR [X] SER REVIEW FEEDBACK
  ├─ Compliance with BAN-PT: [findings]
  ├─ Data Accuracy: [findings]
  ├─ Evidence Completeness: [findings]
  ├─ Writing Quality: [findings]
  └─ Overall Score: ___/100
  ```

- [ ] Coordinate dengan tim standar untuk revisi

**Quality Gate:**
```
LPM SER DRAFT REVIEW
├─ Compliance Check: ✅ PASS / ⚠️ REVIEW / ❌ FAIL
├─ Data Verification: ✅ PASS / ⚠️ REVIEW / ❌ FAIL
├─ Evidence Reference: ✅ PASS / ⚠️ REVIEW / ❌ FAIL
└─ Writing Quality: ✅ PASS / ⚠️ REVIEW / ❌ FAIL
```

**Owner:** LPM + External Reviewer (Week 9) | **Deadline:** End of Week 6

## 🔗 INTEGRATION POINTS

### **Data Flow: Unit → LPM → Akreditasi**

```
UNIT COLLECTS DATA
    ↓
LPM VALIDATES & AUDITS
    ├─ Accuracy check
    ├─ Completeness verification
    ├─ Consistency check
    └─ Quality scoring
    ↓
LPM PROVIDES FEEDBACK
    ├─ Data corrections
    ├─ Missing items identified
    ├─ Quality improvement suggestions
    └─ Approval/rejection
    ↓
UNIT CORRECTS & UPDATES
    ↓
AKREDITASI COORDINATOR USES DATA
    ├─ SER documentation
    ├─ KPI tracking
    ├─ Evidence compilation
    └─ Presentation
    ↓
LPM REVIEWS SER & EVIDENCE
    ├─ Final quality check
    ├─ Compliance verification
    ├─ Accuracy certification
    └─ Approval for submission
```

## 📞 LPM-KOORDINATOR AKREDITASI MEETING

### **Schedule:**
- **Weekly:** Every Tuesday 10:00-11:00 (30 min sync)
- **Bi-weekly:** Every 2nd Thursday 14:00-15:00 (Deep review)
- **Monthly:** Last Friday 09:00-10:00 (Status & planning)

### **Weekly Meeting Agenda (30 min):**
1. **Progress Update** (10 min)
   - Data collection status
   - Quality audit findings
   - Issues & blockers

2. **Quality Issues** (10 min)
   - Critical issues discussion
   - Action items

3. **Next Week Plan** (10 min)
   - Priorities
   - Resource needs

### **Bi-Weekly Deep Review (60 min):**
1. **Phase Review** (20 min)
   - Phase completion status
   - Quality score per standar
   - Gap analysis

2. **Risk & Mitigation** (20 min)
   - Identify risks
   - Mitigation strategies
   - Contingency planning

3. **Action Plan** (20 min)
   - Action items per standar
   - Owner & deadline
   - Resource allocation
