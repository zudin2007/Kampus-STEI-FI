## 📌 OVERVIEW INTEGRASI

Sistem akreditasi STEI FI dikelola melalui **dua folder terintegrasi** yang masing-masing memiliki peran strategis:

### **Folder 1: AKREDITASI & REGULASI** 🏢
Berisi material operasional dan detail yang SUDAH BERJALAN:
- SOP operasional (LPM, LPPM, PRODI)
- Form-form kerja (F-PRODI-01 s/d F-PRODI-11)
- Data dosen (BKD, NIDN, NUPTK)
- Arsip & dokumen existing
- **Peran:** Source of truth operasional

### **Folder 14: AKREDITASI_LEMBAGA** 📋
Berisi strategic framework dan monitoring system YANG BARU:
- Overview strategi akreditasi
- Penjelasan 7 standar BAN-PT
- Master checklist fase persiapan-implementasi
- Timeline detail (week by week)
- KPI dashboard (55+ indicators)
- Monitoring operasional (daily/weekly/monthly)
- LPM quality assurance oversight
- **Peran:** Master coordinator & quality assurance

## 🔄 WORKFLOW INTEGRASI: 5 FASE AKREDITASI

### **FASE 1: PERSIAPAN AWAL (Minggu 1-2)**
**Koordinasi antara Folder 1 & Folder 14:**

- [ ] **Strategic Planning** → AKREDITASI_OVERVIEW.md (Folder 14)
- [ ] **Understand Standards** → BAN_PT_7_STANDAR.md (Folder 14)
- [ ] **Setup Team & Roles** → AKREDITASI_CHECKLIST.md Minggu 1 (Folder 14)
- [ ] **Review Existing SOPs** → Folder 1 SOP LPM, LPPM, PRODI
- [ ] **Identify Data Sources** → Folder 1 (BKD, data dosen, student records)
- [ ] **Schedule Meetings** → LPM_AKREDITASI_KOORDINASI.md (Folder 14)

### **FASE 2: PENGUMPULAN DATA & SER DRAFT (Minggu 2-10)**
**Intensive Collection & Documentation:**

1. **Data Collection** (Using Folder 1)
   - Collect dari BKD Dosen
   - Collect dari data mahasiswa
   - Collect dari forms F-PRODI-01 to F-PRODI-11
   - Collect dari HKI & karya dosen

2. **Data Validation** (Using Folder 14)
   - Validate terhadap KPI targets (KPI_INDIKATOR_AKREDITASI.md)
   - Quality check oleh LPM (LPM_AKREDITASI_KOORDINASI.md)
   - Gap analysis (Identify missing items)

3. **Evidence Compilation** (Folder 14 + Folder 1)
   - Organize evidence di Folder 14 / Dokumen_Pendukung/
   - Link ke source di Folder 1
   - Cross-reference dengan 7 standar

4. **SER Drafting** (Using Folder 14)
   - Draft per standar di Folder 14 / Self_Evaluation_Report/
   - Based on BAN_PT_7_STANDAR.md framework
   - Reference evidence dari Dokumen_Pendukung/

### **FASE 3: FINALISASI & SUBMISSION (Minggu 11-14)**
**Final Quality Gate:**

- [ ] **Data Accuracy**: ≥95% verified (LPM validation)
- [ ] **Evidence Completeness**: 100% compiled
- [ ] **SER Quality**: ≥85/100 score
- [ ] **BAN-PT Compliance**: ≥90% coverage
- [ ] **All KPI Tracked**: 55+ indicators documented
- [ ] **LPM Sign-off**: Formal approval via TUPOKSI_LPM
- [ ] **Timeline Compliance**: Week 13 submission per TIMELINE_AKREDITASI.md

### **FASE 4: VISITASI ASESOR (Minggu 15-18)**
**Preparation & Engagement:**

- [ ] **Presentasi Slides**: Based on Folder 14 standards & KPI
- [ ] **Evidence Organization**: Quick reference per Folder 1 procedures
- [ ] **FAQ Preparation**: Address gaps identified in Folder 14 monitoring
- [ ] **Communication**: Managed per Folder 14 / Laporan_Komunikasi/

### **FASE 5: FOLLOW-UP & IMPLEMENTATION (Minggu 19+)**
**Post-Visitasi Actions:**

- [ ] **Action Plan**: Develop per recommendations
- [ ] **Progress Tracking**: Monthly updates via Folder 14 monitoring
- [ ] **KPI Improvement**: Track improvement vs Folder 14 targets
- [ ] **LPM Oversight**: Continuous quality assurance

## 🎯 CRITICAL SUCCESS FACTORS

### **1. Data Accuracy (Target: ≥95%)**
- Validasi semua data menggunakan Folder 1 source documents
- Quality check oleh LPM sebelum dipakai dalam SER
- Cross-verify dengan multiple sources

### **2. Evidence Completeness (Target: 100%)**
- Compile semua dokumen supporting dari Folder 1
- Organize di Folder 14 / Dokumen_Pendukung/
- Checklist terhadap 7 standar requirements

### **3. SER Quality (Target: ≥85/100)**
- Follow BAN_PT_7_STANDAR.md framework
- Reference evidence secara explicit
- Writing quality tinggi & logical flow
- LPM review & approval sebelum submission

### **4. Timeline Compliance (Critical: Week 13)**
- Monitor progress terhadap TIMELINE_AKREDITASI.md
- Escalate blockers immediately
- Buffer time untuk revisions

### **5. LPM Oversight (Continuous)**
- Weekly Tuesday sync (30 min)
- Bi-weekly Thursday deep review (60 min)
- Quality gate sebelum submission
- Ongoing quality assurance post-visitasi
